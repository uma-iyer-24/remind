# Remind

**Turn anything into a spatial memory.** A digital memory palace: concepts become objects in a 3D room; walk, quiz, and ML-driven reordering reinforces what you're about to forget.

Planning and design — implementation in progress.

- **ML:** Public spaced-repetition datasets, cross-validated forgetting prediction
